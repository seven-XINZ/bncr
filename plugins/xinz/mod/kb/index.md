# 鑫仔智能管家 · 本地知识库索引

这是一套离线可用的纯文本知识库：不依赖大模型 API，不联网也能查。`mod/kb.js` 用 BM25 按标题和条目切块检索，文件修改时间变化会自动重建索引。

## 目录结构

```
mod/kb/
├── index.md          # 本索引
├── nas.md            # NAS / 家庭服务器折腾清单
├── bncr.md           # Bncr 部署与插件踩坑
├── blog.md           # 博客文章索引（RSS 增量同步）
└── tts/
    ├── dolphin.md    # 海豚AI TTS 对接教程（鉴权/HTTP/WS/排错）
    ├── voices.md     # 声线清单（19 个）
    ├── emotions.md   # 情绪与风格清单（26 个）
    └── roles.md      # 角色配方（场景 → 声线 → 情绪 → 参数）
```

## 各库说明

| 文件 | 内容 | 什么时候用 |
| --- | --- | --- |
| nas.md | 机器人、面板、影音、下载、照片、网络、自动化、装机顺序 | 问“NAS 装什么”“家庭服务器方案” |
| bncr.md | docker run、插件规则、常见报错 | 问“Bncr 怎么部署”“插件不生效” |
| blog.md | 博客全部文章标题 + 链接 | 问“博客写过什么”“找某篇文” |
| tts/dolphin.md | Token 登录、接口地址、合成与取音频、350 排错 | 问“海豚AI 怎么接”“为什么 350” |
| tts/voices.md | 3751 条声线、标签分类、热门角色 id | 问“用哪个声线”“有没有某个角色” |
| tts/emotions.md | 37 个情绪 id 及参数建议 | 问“怎么配情绪”“客服用哪个 id” |

## 检索规则

- 查询词会先做扩展：去掉“装什么 / 推荐 / 项目 / 怎么 / 教程”等泛词，保留实体。
- 命中阈值默认 1.0，可在插件配置 `kbThreshold` 调整；调高更严，调低更松。
- 返回按相关度排序，最多取前 3 块，带文件名和标题，方便回溯。
- 没有任何命中时，会记入生词本，用 `ai 生词本` 查看。

## 维护方式

1. 手写：直接改 `mod/kb/**/*.md`，保存即生效（mtime 触发重建），不用重启容器。
2. 自动：`mod/kb-sync.js` 定时抓博客 sitemap，把新文章标题和链接追加到 `blog.md`。
3. 新增分类：在 `mod/kb/` 下建子目录即可，`kb.js` 会递归扫描。
4. 写条目时用 `#` 标题 + 一条一个要点，检索按标题和单条 bullet 切块，长段落反而不好命中。

## 常用命令

```
ai 知识库          # 看有哪些库、多少块
ai 海豚AI 怎么接    # 查 TTS 对接
ai 哪个声线适合旁白  # 查声线
ai 客服用什么情绪    # 查情绪
ai 博客写过什么      # 查博客索引
```
