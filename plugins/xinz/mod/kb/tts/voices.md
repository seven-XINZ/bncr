# 海豚AI 声线清单与选声指南

海豚AI 有两个声线池，`voice_id` **不重叠**：

| 池 | 请求 | 条数 | 说明 |
| --- | --- | --- | --- |
| 普通站通用池 | `GET /flashsummary/voices?token=<TOKEN>`（不传 `tag_id`） | 537 | 男女 246/291；通用、方言、童声、多情感 |
| 二次元站角色池 | `GET /flashsummary/voices?language=zh-CN&tag_id=1&token=<会员TOKEN>` | 3751 | 男女 1517/2234；原神、星铁、日漫、鸣潮等 |

二次元池的 3751 条里，同一个角色往往有多个“情绪版本/语气版本”，所以 3751 不是 3751 个不同角色。普通 Token 调二次元角色常见 `350`，不要混用。

## 一、先按场景选“类型”

| 场景 | 推荐声线 | voice_id | 理由 |
| --- | --- | --- | --- |
| 普通站通用男声 | 云健-多情感-情感男声 | 260 | 普通池，普通 Token 可用 |
| 普通站通用女声 | 晓萱-情感女声 | 256 | 普通池，普通 Token 可用 |
| 二次元旁白 | 旁白 | 1841 | 二次元池，需 acgn 会员 Token |
| 二次元男声 | 男声 | 2082 | 二次元池，需 acgn 会员 Token |
| 二次元播报女声 | 播报女声 | 2044 | 二次元池，需 acgn 会员 Token |
| 智能管家 | 播报女声 / 男声 | 2044 / 2082 | 短句清楚，适合 TTS 助手 |
| 有声书 | 旁白 + emotion 25 | 1841 | 旁白情绪 id=25，语速 0.9 |

| 二次元角色 | 见下方角色表 | — | 必须用 acgn 会员 Token |

> `emotion` 是数字 id，完整表见 `emotions.md`。

## 四、选声步骤

1. 先定语言：中文优先 `language=zh-CN`；日漫角色名字里带“日语”的，`to_lang` 用 `auto` 或 `EN` 前先试听。
2. 再定类型：旁白/播报/客服选 1841、2082、2044 这类标准声线；角色扮演再进 ACGN。
3. 再定角色：用 `/voices` 搜 `voice_name` 关键词，拿到 `id`。
4. 最后定情绪：同一角色有多个版本时，优先选已经带情绪后缀的版本；没有就传 `emotion` 数字 id。
5. 试听：`voice_audio_path_v2[].demoPath` 是试听文件，先听再批量合成，省额度。

## 五、避坑

- `language` 字段全站基本都返回 `zh-CN`，不代表角色只会中文；日漫角色要看名字里的“日语”或作品标签。
- 同名角色 id 不同，别拿一个 id 当所有版本用。
- 二次元角色需要 acgn 会员 Token，普通 Token 报 `350` 是权限问题。
- 3751 条里包含同一角色的多情绪变体，按“角色 + 版本”理解，不要按“3751 个角色”宣传。
