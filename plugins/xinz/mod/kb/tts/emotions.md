## 怎么选

1. **先定用途**：客服 21、旁白 25、新闻 22、有声书 20、广告 23、直播 19。
2. **再定情绪强度**：日常 1、开心 2、悲伤 4、生气 3；剧情向再上 13/24。
3. **长文本用 50**：稳定版适合几千字连续朗读，减少情绪跳变。
4. **一句一个情绪**：要变化就切段，不要在一段里反复换 id。
5. **角色自带情绪版本**：如果 `voice_name` 已经带“开心/生气/旁白”等后缀，优先用该版本，`emotion` 传 0 或对应 id 都先试听。

## 注意

- 情绪 id 不是越大越好；3 生气、13 癫狂这类高强度情绪，文本和标点不配合会显得假。
- 角色不支持某个情绪时，可能被忽略或返回参数错误；先单条试听，再批量。
- 情绪和语速要配套：悲伤/哭腔把 `speed_factor` 降到 0.85–0.95，广告/直播提到 1.1–1.15。
