## 关于 Bncr 框架

Bncr 是一个开箱即用的 Node.js Chat Robot（会话式机器人）框架，基于 OOP 函数响应式编程，占用小、响应快、开发易，允许开发者创建可测试、可扩展、松散耦合且易于维护的应用程序，架构受 Koishi 与 sillyGirl 启发。

- 多平台多账户接入：QQ / 微信 / Telegram 等多账号同时在线
- TypeScript OOP 函数响应式，源码体积小，响应快
- 插件开发高度封装，提供简便的系统方法
- 异步 / 同步执行自由控制（async/await / Promise）
- 不止于聊天机器人：原生支持 npm/yarn，可扩展为网站、图片服务器、资源共享平台等服务

## 微信 ClawBot 适配器（Adapter/wxClawBot.js）

腾讯官方「微信 ClawBot」通道（iLink Bot 协议）的 Bncr 适配器，扫码即用，不依赖 hook。

1. Bncr 启动后打开 `http://<你的地址>:9099/api/bot/wxclawbot/qr` 扫码
2. 手机微信：我 → 设置 → 插件 → 微信 ClawBot → 开始扫描（出现配对数字时在页面输入）
3. 扫码绑定的微信号自动成为本适配器的 owner（即管理员），凭据存 BncrDB，重启无需重扫
4. 仅支持私聊；官方限速约 7 条 / 5 分钟，适配器内做了令牌桶排队
5. 返回 `-14` 表示 token 失效，按官方要求冷却 1 小时后访问 `/api/bot/wxclawbot/relogin` 重扫

调试接口：`/api/bot/wxclawbot/status`（状态）、`/api/bot/wxclawbot/ctx`（已缓存会话）、`/api/bot/wxclawbot/say?text=`（主动发文本）。

## 智能管家（plugins/xinz/智能管家.js）

用一句话调度整台 Bncr：把自然语言交给大模型做路由，自动挑出对应插件并执行，不需要记命令。

**触发方式**

- `prefix` 模式（默认）：`ai 成都今天热不热`、`ai 运行状态`、`ai 摸鱼`
- `auto` 模式：授权范围内的所有消息都交给管家判断（慎用，聊天内容也会被路由）

**授权**

- `授权用户`：每行一个 userId，支持 `*` 通配
- `授权群`：每行一个群号，支持 `*`
- 未配置时可被 Bncr 管理员、wxClawBot 绑定人直接使用

**路由优先级**

1. 配置了 `API Key` → 大模型从插件表里选插件并生成匹配规则的消息
2. 未配置 → 原文直接匹配各插件 `@rule`
3. 都不中 → 按关键词给出候选建议，不盲目执行

**安全**

- 标了 `@admin true` 的插件（SSH、容器操作、qb 操作等）只有管理员能通过管家调度
- `屏蔽插件` 默认排除管家自身和 AI 聊天类插件，避免递归调用
- 插件目录 60 秒缓存，新增插件无需重启

## 智能管家 · 人格与情绪（v1.1.0）

v1.0 只是个路由器，v1.1 给了它人格、情绪和判断力。

**人格**

- `名字`、`性格设定` 全部可配，默认是「嘴上毒舌、心里靠谱」的口语化风格
- 闲聊走人格回复，办正事立刻收住玩笑，先办事再说话

**情绪系统（默认开启）**

| 情绪 | 触发 | 表现 |
|---|---|---|
| 平静 | 初始 / 久未对话后回归 | 话少但都在点上 |
| 开心 | 被夸、聊得投机 | 愿意多聊两句，会开玩笑 |
| 兴奋 | 高兴且体力充足 | 短句、感叹、容易上头 |
| 烦躁 | 被骂、被连续催 | 回话变短带点不耐烦，但活照办 |
| 疲惫 | 体力低 / 消极互动 | 回答简短，能一句说完不说两句 |

- 每次交互扣 2 点体力，被夸 +1、被骂 -2；6 小时没对话自动回平静并回血
- 情绪状态和每个人的好感度存在 BncrDB 的 `智能管家状态` 键里，重启不丢
- 对每个用户单独记好感度：`熟人` 会放松开玩笑，`不太对付` 说话会冲一点

**决策**

一次大模型调用同时决定「聊 / 办 / 不接」：

- `chat`：闲聊、吐槽、问看法 → 用人格口吻回，40 字以内
- `run`：能落到插件 → 输出插件名 + 严格匹配其规则的命令
- `none`：没把握 → 直接说不懂，不瞎编

没配 Key 时退回规则精确匹配 + 关键词候选，只给建议不乱执行。

## 智能管家 · 记忆与词库（v1.2.0）

v1.2 让它即使**不接大模型也能干活**，接了大模型则更懂你。

**记忆（按人存，重启不丢）**

| 说法 | 效果 |
|---|---|
| `ai 记住 我常住成都，喜欢重辣` | 记一条事实，闲聊时自动带进上下文 |
| `ai 忘记 成都` | 按关键词删掉相关记忆 |
| `ai 你记得什么` | 列出当前用户的所有记忆 |

- 记忆按平台 + 用户 ID 分开存，存在 BncrDB 的 `memory` 键
- 闲聊和大模型决策时会把记忆摘要拼进 prompt，不用每次重复交代

**词库（无大模型的兜底）**

- 内置意图词表（天气、热搜、疯狂星期四、插件工坊等），一条需求 → 对应插件命令
- `ai 词库` 查看全部意图；`ai 学词 打车 => 天气 成都` 可自己加词条，存 `lexicon` 键
- 大模型不可用 / 没配 Key 时，直接用词库做匹配 + 候选提示，绝不瞎执行

**三层降级**

1. 有大模型：人格 + 情绪 + 记忆一起决策
2. 大模型掉线：自动回退本地词库
3. 词库不中：给出候选清单，等你说下一步

## 插件工坊（plugins/xinz/插件工坊.js）

一句话让大模型**现场写插件**，只给管理员用。

- 用法：`ai 做个插件 每天 8 点把成都天气推到群里`，也可以直接 `做个插件 ...`
- 生成的文件统一放在 `plugins/自动生成/`，**和手写插件完全分开**，方便单独备份或清空
- 落盘前做三道检查：语法编译、`@rule/@cron` 元信息是否存在、高危调用（child_process / 删文件 / eval）直接拒写
- 同名插件默认不覆盖，需要覆盖在工坊配置里打开开关
- 生成记录存 BncrDB，`插件工坊` 可查看清单；新插件重启 Bncr 后生效
- 需要先配 API Key（默认火山 Ark，`doubao-seed-2-1-turbo`）
