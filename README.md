# Bncr · 全平台智能中枢

![封面](docs/readme-cover.webp)

一个入口接管全平台：微信、QQ、Telegram、Web、SSH 都能对话；会记事、有情绪，没大模型也能跑，还能挂 Python 技能。

这个仓库是 [Bncr（无界）](https://github.com/Anmour/Bncr) 的个人部署版，额外做了三件事：

1. **多平台适配器**：微信 ClawBot 扫码即用，QQ/TG/PGM/Web/SSH 复用同一套插件
2. **智能管家**：唯一入口，把全仓 40+ 插件收进一张嘴，装上新插件自动入库
3. **插件工坊 + mod 模块**：一句话生成插件；mod 提供 JSON 存储与 Python 技能通道，Bncr 不再只能用 JS

> 所有能力都有降级路径：大模型挂了走本地词库，词库不中给候选，绝不瞎执行。

## 核心特性

| 能力 | 说明 |
|---|---|
| 自然语言调度 | 「成都天气」「微博热搜」「服务器怎么样」直接落到对应插件，不用背命令 |
| 人格与情绪 | 平静/开心/兴奋/烦躁/疲惫五种状态，按互动变化，6 小时无人自动回血 |
| 好感度 | 每个用户单独记，熟人放松、生人收敛 |
| 记忆 | `记住` / `忘记` / `你记得什么` / `清空记忆`，按用户隔离，重启不丢 |
| 词库 | 内置意图表 + `学词` / `删词` 自定义，**不接大模型也能干活** |
| 自主生成插件 | `做个插件 ...`，落盘到独立目录，三道检查后等待重启加载 |
| 单一入口 | 管家优先级最高，`ai` 前缀全归它，其他插件不再抢话 |

## 全平台

Bncr 是适配器架构，管家不绑定某个平台。当前仓库自带这些适配器：

| 适配器 | 平台 | 说明 |
|---|---|---|
| wxClawBot | 微信（ClawBot/iLink） | 扫码登录，文本/图片/文件，可选 TTS |
| wechaty | 微信（Wechaty） | 需配 token / padlocal |
| wxXyo / wxQianxun / wxKeAImao | 微信（第三方协议） | 按各自网关填地址 |
| wxMP / wxWork / wxWorkKF | 公众号 / 企业微信 / 企微客服 | 回调模式 |
| qq / pgm | QQ（OneBot / go-cqhttp） | 正向或反向 WS |
| tgBot | Telegram | Bot Token |
| web | 网页对话 | 内置 Web 面板 |
| ssh | SSH 终端 | 命令行直接聊 |
| HumanTG | Telegram 人机混合 | 人工接管 |
| wechatFerry | 微信（PC Hook） | 需对应版本客户端 |

插件里的 `@platform` 决定它能在哪些平台跑；管家调度时会照常把消息交给插件，平台差异由适配器抹平。

## 快速开始

官方镜像用 `docker run`，不要套 compose：

```bash
docker run -itd --name bncr --restart=always \
  -p 9090:9090 \
  -v /vol1/1000/docker/1panel/apps/BncrData:/bncr/BncrData \
  -e TZ=Asia/Shanghai \
  anmour/bncr:latest
```

1. 打开 `http://<host>:9090` 进面板
2. 在「适配器」启用需要的平台（微信选 `wxClawBot` 扫码）
3. 在「插件配置」填 `智能管家` 的大模型 Key（可留空，留空走词库）
4. 任意平台发一句 `ai 你会什么` 验证链路

> 授权中心域名偶尔解析到 IPv6 导致启动卡住，可加 `--add-host bncr.619030.xyz:172.67.170.203`。

## 微信适配器 wxClawBot

- 扫码登录，凭证与游标存 `BncrDB('wxClawBot')`，重启免扫码
- 长轮询收消息，发送做限速与重试，避免风控
- 支持文本、图片、文件；收到图片可保存到本地再交给插件处理
- 与 `微信TTS.js` 联动：开关打开后，文本回复自动转语音再发出
- 配置项：`是否开启适配器`、`channel_version`（协议版本，格式必须是三段数字）

## 智能管家（plugins/xinz/智能管家.js）

**唯一入口**。启动后优先级 `999999`，所有 `ai` / `小新` / `管家` 开头的消息都先到它这里，再由它决定调哪个插件。

### 触发

| 说法 | 说明 |
|---|---|
| `ai 成都天气` | 带前缀，最稳 |
| `小新 微博热搜` | 别名前缀，逗号冒号可有可无 |
| `天气 成都` | `auto` 模式下，命中插件规则也会被接管 |
| `ai 随便聊聊` | 走人格闲聊，不硬凑插件 |

接管开关默认开启：所有消息先到管家，命中词库、闲聊词或某个插件的**具体规则**才接手，其余 `next` 还给别的插件；未授权用户的消息直接放行，不会把群聊吞掉。

### 命令

| 命令 | 作用 |
|---|---|
| `ai 记住 我常住成都，喜欢重辣` | 记一条事实（上限 40 条/人） |
| `ai 忘记 成都` | 按关键词删记忆 |
| `ai 你记得什么` | 列出当前用户的记忆与好感度 |
| `ai 清空记忆` | 清空事实与上下文，名字保留 |
| `ai 词库` | 查看意图表与自学词条 |
| `ai 学词 查快递 => 天气 快递` | 加词条，立即生效 |
| `ai 删词 查快递` | 删词条 |
| `ai 你会什么` | 按当前插件数生成能力清单 |
| `ai 刷新插件` | 立即重新扫描插件目录（新装插件不用重启） |
| `ai 技能` | 列出 mod 技能 |
| `ai 跑 <技能名> [参数]` | 执行 mod 里的 python/shell 技能 |

### 情绪

| 情绪 | 触发 | 表现 |
|---|---|---|
| 平静 | 初始 / 久未对话 | 话少但都在点上 |
| 开心 | 被夸、聊得投机 | 愿意多聊两句 |
| 兴奋 | 开心且体力足 | 短句、感叹 |
| 烦躁 | 被骂、被连催 | 变短、带点不耐烦，活照办 |
| 疲惫 | 体力低 / 消极互动 | 能一句说完不说两句 |

每次交互扣 2 点体力，被夸 +1、被骂 -2；6 小时无对话回平静并回血 20。

### 三层降级

1. 有大模型：人格 + 情绪 + 记忆 + 插件目录一起决策
2. 大模型掉线/没配 Key：本地词库匹配
3. 词库不中：给候选建议，不乱执行

模型返回的执行计划还要再过一道闸：插件必须真实存在、命令必须能匹配该插件的规则，否则降级成闲聊。

### 本地知识库与多轮（v1.7）

**知识库**放在 `plugins/xinz/mod/kb/`（支持子目录，递归扫描），启动时切块建 BM25 索引（文件变了自动重建），纯本地、不联网、不消耗模型：

| 文件 | 内容 |
|---|---|
| `nas.md` | NAS / 家庭服务器折腾清单：机器人、面板、影音、下载、照片、网络、自动化，带 GitHub 链接与装机顺序 |
| `bncr.md` | 本机 Bncr 部署命令、插件规则、踩坑（IPv6 授权、`@rule` 字面量、Actions 自动提交…） |
| `blog.md` | 鑫仔博客全部 93 篇文章的标题与链接（抓自 `blog.xinz.fun:4443` 的 sitemap） |

```text
ai 知识 NAS 装什么       → 命中清单与项目
ai 知识 3x-ui 回家隧道    → 命中博客原文链接
ai 知识库               → 列出已索引文件与块数
ai 博客里写过什么         → 直接走知识库，不走大模型
```

**多轮能力**：

- 缺参数会追问：「ai 天气」→「还差个城市」→「成都」→ 执行
- 指代会接上：「ai 它怎么样」直接重跑上一个操作（10 分钟内有效）
- 危险操作先确认：「重启/删除/清空/格式化/kill/rm」类命令先回「确认」才执行，60 秒有效，回「取消」放弃
- 没接住的话自动进生词本，`ai 生词本` 按次数排序并给出候选插件，`ai 学词 关键词 => 插件名` 补上，`ai 清空生词` 重置

### 智能回应判断（该不该接话）

群里不点名时不用「每句都回」，管家自己算一遍：**这条值不值得我开口。**

| 加分 | 减分 | 直接拦 |
|---|---|---|
| 问句/求助（吗、怎么、帮我、查下） | 纯附和（哈哈、666、收到、好） | 本群静音中 |
| 动作词（查、开、重启、部署、装） | 纯表情、纯链接、纯图片 | 免打扰时段 |
| 兴趣词（插件、报错、接口、docker…） | 在 @ 别人（不是跟我说） | 接话冷却未过 |
| 明确命令（命中具体插件规则） | 太短/太长 | 分数低于阈值 |

- 阈值默认 30，心情会调线：烦躁 +10、疲惫 +8、兴奋 -8，体力低于 30 再减分
- 同一个群两次**主动**接话至少隔 120 秒；被明确求助（高分）可以插队
- 点名、`ai` 前缀、私聊三条通道永远不受限
- 每次判断都写日志，能复盘「刚才那句为什么没回」

常用命令：

```text
ai 回应              看当前策略、本群状态、最近 6 条判断
ai 为什么没回        最近一次沉默的分数和原因
ai 想不想回 晚上吃啥  预演打分，告诉你卡在哪
ai 闭嘴 30           本群 30 分钟不主动接话（点名/指令照常）
ai 说话              提前解禁
ai 阈值 45           调接话门槛，越高越闷
ai 冷却 60           调同群主动接话间隔（秒）
```

### 离线智能（不接大模型）

没 Key 也要像个管家，不是关键词机器人：

| 能力 | 例子 |
|---|---|
| 同义词归一 | 「天气咋样」「查下热搜」「几点了」自动归一 |
| 错字/语序容错 | 「气天」也能落到天气插件（二元组 + 字符重合，阈值 0.66） |
| 内置时间日期 | 「现在几点」「今天几号」本地时间算，不走网络 |
| 内置计算 | 「算一下 128*7+9」安全表达式求值，不执行任意代码 |
| 随机决策 | 「抛硬币」「掷骰子」「随机选 A 还是 B」 |
| 插件检索 | 「找插件 快递」按名称+描述匹配，列出对应规则 |
| 多意图 | 「天气和热搜」拆成两段顺序执行，最多 3 段 |
| 观点与短句 | 「你觉得靠谱吗」给态度；短句不会硬凑插件 |
| 问候按时段 | 早/中/晚不同回复，晚安直说 |
| 情绪化回复 | 同一句话按心情换语气，不重复模板 |

| Bncr_ChatGP | `yy` |

## mod 模块（plugins/xinz/mod）

插件目录下的数据层，不依赖数据库，文件即数据。

```text
mod/
├── store.js        # 命名空间 KV 存储（原子写入）
├── data/           # 每个命名空间一个 JSON，可直接改
├── skills.json     # 技能清单
└── skills/         # python / shell 脚本
```

**存储**

```js
const store = require('./mod/store');
await store.set('smart', 'state', {...});   // 写
await store.get('smart', 'state', {});      // 读
await store.push('logs', 'items', {...}, 100); // 队列
```

管家已把记忆、词库、情绪状态迁到 `mod/data/smart.json`，出问题直接看文件，不用翻 LevelDB。

**技能（让 Bncr 不止能用 JS）**

`skills.json` 里登记脚本，管家按名字调用：

```json
{
  "skills": [
    { "name": "技能测试", "desc": "返回主机名与时间", "file": "skills/ping.py", "keywords": ["技能测试"] }
  ]
}
```

```text
ai 技能                  # 列出已注册技能
ai 跑 技能测试 你好       # 执行 python3 skills/ping.py 你好
```

脚本 stdout 直接回给用户，15 秒超时，只允许授权用户触发。

## 插件工坊（plugins/xinz/插件工坊.js）

一句话让大模型现场写插件，仅管理员可用。

```text
ai 做个插件 每天 8 点把成都天气推到群里
```

- 生成物落在 `plugins/自动生成/`，与手写插件完全隔离
- 落盘前三道检查：语法编译、规则元信息是否齐全、高危调用（child_process / 删文件 / eval）直接拒写
- 同名默认不覆盖，可在配置里打开
- 新插件重启 Bncr 后加载，之后就能被管家直接调度

需要先在插件配置里填 API Key（默认火山 Ark，模型 `doubao-seed-2-1-turbo`）。

## 常见问题

**扫码后一直掉线？**
检查 `channel_version` 是否为三段数字，以及服务器出网是否正常。

**发了 `ai xxx` 没反应？**
先看面板日志有没有 `智能管家` 的加载记录；再确认自己在授权名单里（默认只有管理员和微信主人）。

**大模型报 `EAI_AGAIN`？**
是 DNS 解析失败，不是 Key 问题。换 DoH 或给容器配 DNS，再重试。

**插件工坊说没 Key？**
它只走大模型，必须先填 API Key；不填就用不了，但管家本身不受影响。
